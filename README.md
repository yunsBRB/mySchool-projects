## Ouvrir un projet

Chaque application possède son dossier et ses commandes de lancement. Ouvrir le dossier de l'application dans l'IDE, puis suivre son README.

Pour le Pokédex dans WebStorm : ouvrir `angular/pokedex`, puis lancer `npm ci` et `npm start` dans le terminal. Adresse : http://localhost:4200.

Le projet de cours précédemment à la racine de `angular/` se trouve maintenant dans `angular/Yuns&Wilson/`. Son contenu a été conservé.
