# Angular & TypeScript
 
| Projet | Contenu |
| --- | --- |
| [Yuns & Wilson](Yuns&Wilson/) | Exercices du cours : chronomètre, produits et panier |
| [Pokédex](pokedex/) | Catalogue Pokémon, favoris, équipe et comparaison |

Chaque dossier est une application indépendante avec son propre `package.json`.
Dans WebStorm, ouvrez directement le dossier du projet choisi.

## Pokédex

```bash
cd angular/pokedex
npm ci
npm start
```

## Projet de cours

```bash
cd "angular/Yuns&Wilson"
npm ci
npm start
```

Les commandes `cd` partent de la racine du dépôt. Les deux applications utilisent le port 4200 : lancez-en une à la fois.

L'ancien contenu de `angular/` a été déplacé intact vers `angular/Yuns&Wilson/`.
